## Scope and important limitations

The 40-document HTML file is an unchanged copy of a previously assembled **compiled** record, incorporating transcriptions, editorial notes and later correspondence. Original document numbers and links are retained. The five uploaded evidence files were verified against their source copies using identical GitHub blob hashes. That confirms byte identity, not independent authentication of the original clinical records.

The [cross-reference](EVIDENCE_CROSS_REFERENCE.md) identifies source-note groups that the local collection only partially covers. The [recipient-and-knowledge audit](RECIPIENT_AND_KNOWLEDGE_AUDIT.md) identifies the principal missing evidence: full clinical handover/version histories, the complete March 2023 urgent-referral and nurse correspondence, potential witnesses to the reported bedside encounter, and the complete PAR/SIMT documentation and source inventory.

The purpose of these omissions being identified is to make the evidence requirements clear to counsel; no unseen document should be treated as having been examined or as supporting a particular conclusion.
